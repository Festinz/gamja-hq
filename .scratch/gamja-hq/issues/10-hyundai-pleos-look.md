# 10: 현대차·Pleos 톤의 테마와 감자 재디자인

**What to build:** 화면이 유아용처럼 보이지 않고 현대차 차량 화면처럼 읽힌다. 강조색은 현대 블루, 바탕은 샌드 계열 중립색, 서체는 Pleos 공식 서체인 Asta Sans다. 감자는 굵은 외곽선과 볼터치를 빼고 무덤덤한 표정의 절제된 그림으로 바꾼다. 유머는 진지한 상황판 화면과 하찮은 감자의 대비에서 나온다.

**Blocked by:** 09

**Status:** resolved

- [x] 밝은 테마의 강조색이 현대 블루(#002C5F), 어두운 테마의 강조색이 액티브 블루(#00AAD2)다
- [x] 본문과 제목이 Asta Sans로 그려지고, 서체 파일은 앱에 같이 묶여 오프라인에서도 나온다
- [x] 감자 그림에 굵은 외곽선, 볼터치, 팔다리가 없다
- [x] 홈이 "작전 상황판"으로 바뀌어 감자 한마디, 숫자 타일, 오늘의 운행, 쌓인 기록 순으로 읽힌다
- [x] 밝은 테마와 어두운 테마 모두 글자 대비 4.5:1 이상으로 읽힌다
