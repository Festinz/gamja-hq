# 15: 공모전 가이드와 다른 출품작에 맞춘 고도화

**What to build:** 공식 가이드(appdevchallenge.auto-hmg.io/guide)가 요구하는 제출물 형식을 갖추고, 같은 공모전의 다른 출품작 시연 영상처럼 Pleos Connect 에뮬레이터(v2.1.0, 2560×1440, 160dpi)의 앱 창에서 읽히는 크기로 화면을 키운다. 감자 음성은 기계음이 아닌 자연스러운 음성을 우선한다.

**Blocked by:** 14

**Status:** claimed

- [x] 앱 창 폭에 비례해 글자와 간격이 커진다 (1,680px 창에서 기준 글자 27px)
- [x] 버튼과 입력 높이가 rem 단위라 같은 창에서 54~81px 이다
- [x] 주행 화면의 한마디가 가장 큰 글자로 나온다
- [x] 자동 시연 중 장면 자막(①~⑤)과 가상 차량의 기어·속도가 화면 위에 나온다
- [x] README 에 가이드 필수 항목(한 줄 소개, 실행 방법, 테스트 환경, 에뮬레이터 버전과 화면 규격, APK 위치)이 있다
- [x] release APK 가 빌드되고 서명이 검증된다
- [x] 브라우저에서 가장 자연스러운 한국어 음성을 고르고, 설정에서 미리 들을 수 있다
- [x] Android 에서 자격 증명이 있으면 Pleos 서버 음성(HYBRID)에 등록한다
- [x] APK 파일 이름을 `팀명_앱이름_release.apk` 로 맞춘다 (`apk/시나브로_감자작전본부_release.apk`)
- [x] 실제 차량에 연결된 상태에서도 정체만 "시험 값"으로 넣을 수 있다 (에뮬레이터는 내비 정체를 만들지 못한다)
- [ ] Pleos Playground 자격 증명을 넣고 서버 음성이 실제로 더 자연스러운지 듣는다
- [x] 에뮬레이터의 앱 창(1682×1210)에서 크기가 적당한지 확인했다
- [ ] 에뮬레이터와 Virtual Console 로 시연 영상을 다시 찍는다
