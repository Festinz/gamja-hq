# 06: 추억 회상과 타임캡슐

**What to build:** 저장한 작전일지가 예전 같은 날짜의 것이면 홈에 회상 카드로 돌아온다. 예전에 온 지역에 다시 주차하면 그때의 일지를 보여준다. 감자를 처음 만난 날도 기념일로 돌아온다. 주차한 곳에 한 문장 타임캡슐을 남기면 그 지역에 다시 왔을 때 감자가 들려준다. 시뮬레이터에서 날짜를 돌려 시연할 수 있다.

- [x] 같은 지역에 다시 주차하면 결과 화면에 그 지역의 지난 일지가 뜬다

- [x] 회상 카드는 닫을 수 있고 같은 날 다시 뜨지 않는다
- [x] 시뮬레이터에서 날짜를 하루, 한 달, 일 년 앞으로 돌릴 수 있다
