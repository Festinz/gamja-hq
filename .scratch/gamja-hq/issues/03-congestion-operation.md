# 03: 정체 구간 공동작전

**What to build:** 정체 진입 신호가 오면 감자가 감자 부대를 발견했다고 한 줄로 알리고, 공동작전이 조작 없이 진행된다. 작전 이름은 시나리오와 시간대에 맞는다. 감자 교류에 동의하지 않았으면 부대에 묶이지 않는다.

**Blocked by:** 02

**Status:** resolved

- [x] 교류 동의가 있으면 정체 진입 때 공동작전이 시작되고 부대 크기가 정해진다
- [x] 교류 동의가 없으면 공동작전이 시작되지 않고 감자는 혼자 버틴다는 대사를 한다
- [x] 정체 중 화면에는 다른 감자의 목록, 이름, 위치가 보이지 않는다
- [x] 주차하면 작전이 완료 처리된다 (정체 중 주차 포함)
- [x] 한 운행에서 정체가 두 번 오면 같은 작전에 이어서 기록된다
- [x] 가상 부대라는 사실이 "시뮬레이션"으로 표시된다
