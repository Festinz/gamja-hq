# 07: 임무 (커피 운송작전, 주차비 돌려줘)

**What to build:** 임무 화면에서 커피 운송작전을 열어 일반 경로와 방지턱이 적은 경로를 시간과 방지턱 수로 견주고 고른다. 고른 임무는 다음 운행의 감자 대사와 작전일지에 반영된다. 주행 중이 아니면 주차비 돌려줘 알림 시간을 정할 수 있고, 시간이 되면 감자가 할인 등록을 상기시킨다.

**Blocked by:** 05

**Status:** resolved

- [x] 두 경로의 예상 시간과 방지턱 수가 나란히 보이고 하나를 고를 수 있다
- [x] 수치가 가상 예시이고 방지턱 수가 흔들림을 보장하지 않는다는 안내가 있다
- [x] 커피 운송작전을 건 운행에서는 감자 탑승 대사와 작전일지에 임무가 언급된다
- [x] 주행 잠금 중에는 주차비 알림을 걸 수 없다
- [x] 알림 시간이 되면 상기 안내가 뜨고 "등록 완료"로 닫을 수 있다
- [x] 임무는 핵심 화면(홈, 결과, 일지)보다 낮은 위계로 보인다
