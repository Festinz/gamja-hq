# 05: 작전일지

**What to build:** 주차 뒤 감자가 쓴 작전일지 초안이 만들어진다. 초안은 그날 기록된 사건(시나리오, 정체, 공동작전, 스티커, 임무)을 엮은 이야기다. 메모와 사진을 붙여 저장하거나 버릴 수 있다. 저장한 일지는 목록에서 다시 열고 지울 수 있다.

**Blocked by:** 04

**Status:** resolved

- [x] 운행 기록 동의가 있으면 주차 때 초안이 생기고, 없으면 생기지 않는다
- [x] 초안 본문은 실제 기록된 사건만 언급한다(정체가 없었으면 정체 얘기가 없다)
- [x] 메모(한 줄)와 사진 한 장을 붙일 수 있다
- [x] 저장하면 목록 맨 위에 나타나고, 버리면 어디에도 남지 않는다
- [x] 목록은 최근 날짜가 위이고, 하나를 열면 전체 본문과 메모, 사진이 보인다
- [x] 저장한 일지를 확인 절차를 거쳐 지울 수 있다
- [x] 일지에는 지역 이름까지만 있고 좌표나 경로가 없다
- [x] 일지가 없을 때 목록에 빈 상태 안내가 보인다
