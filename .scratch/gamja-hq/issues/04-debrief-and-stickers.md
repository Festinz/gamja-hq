# 04: 주차 후 작전 결과와 스티커

**What to build:** 주차하면 작전 결과 화면이 열린다. 함께한 감자 수, 정체 시간, 받은 스티커가 공개된다. 정해진 스티커 중 하나를 골라 부대에 답례할 수 있다. 정체가 없었던 운행에는 무사 귀환 결과가 나온다.

**Blocked by:** 03

**Status:** resolved

- [x] 주차 직후 결과 화면이 뜨고 함께한 감자 수와 받은 스티커가 보인다
- [x] 스티커 수신을 꺼두었으면 받은 스티커가 없다
- [x] 답례 스티커는 고정 목록에서만 고르고 자유 입력란이 없다
- [x] 답례는 한 운행에 한 번이고, 보낸 뒤에는 보낸 스티커가 표시된다
- [x] 정체가 없었으면 "무사 귀환" 결과가 나오고 스티커 영역이 없다
- [x] 받은 스티커가 가상 감자에게서 왔다는 표시가 있다
