# 11: 계급, 연속 탑승, 누적 기록

**What to build:** 운행을 마칠 때마다 감자의 누적 기록이 쌓이고 계급이 오른다. 매일 타면 연속 탑승 일수가 이어진다. 다시 탈 이유를 만드는 장치이며, 공모전 심사의 사업성(지속 이용) 항목에 답한다.

**Blocked by:** 05

**Status:** resolved

- [x] 운행을 마치면 마친 운행 수, 공동작전 수, 함께한 감자 수, 받은 스티커 수, 정체 시간이 누적된다
- [x] 일지를 저장하지 않아도 운행은 누적된다
- [x] 계급은 마친 운행 수로 오르고, 다음 계급까지 남은 횟수가 보인다
- [x] 연속 탑승은 하루에 한 번만 세고, 하루를 거르면 0으로 돌아간다
- [x] 상황판에 계급, 연속 탑승, 함께한 감자가 숫자 타일로 보인다
