# 14: Android 앱과 Pleos SDK 신호 연결

**What to build:** 웹앱을 Android 앱(WebView)에 묶어 Pleos Connect 에서 실행하면, 시뮬레이터 대신 실제 차량 신호로 운행이 흐른다. 기어가 P 를 벗어나면 출발, P 로 돌아오면 주차, 내비 경로 위 정체 구간에 들어서면 공동작전이 시작된다. 출발지와 목적지 이름은 내비에서 온다. 감자의 한마디는 차량 스피커로 나온다. Pleos 서비스가 없는 기기에서는 시뮬레이터로 동작한다.

**Blocked by:** 12, 13

**Status:** resolved

- [x] 코어가 시나리오 없는 운행을 받는다 (출발지, 목적지, 정체 도로가 운행 중에 알려짐)
- [x] 웹앱이 네이티브 메시지(신호, 운행 정보, 연결 상태, SDK 이벤트)를 받아 같은 코어에 넣는다
- [x] 실제 신호를 받는 동안 상단 표시가 "Pleos 연결됨"으로 바뀌고 시뮬레이터 버튼이 사라진다
- [x] 작전 결과를 닫지 않고 다시 출발하면 지난 일지를 저장하고 새 운행을 시작한다
- [x] 기어 변화 → 신호, 정체 판정, 주소 → 지역 이름 로직이 SDK 없이 단위 테스트된다
- [x] 디버그 APK 가 빌드된다
- [x] Pleos Connect 에뮬레이터에서 기어 변화에 따라 화면이 바뀐다 (Emulator v2.1.0, Virtual Console로 P → D → P)
- [x] 주행 중에도 시스템이 앱을 가리지 않는다 (`distractionOptimized` 선언)
- [ ] 에뮬레이터에서 TrafficCongestionInfo.offset 의 실제 의미를 확인하고 정체 판정 기준을 맞춘다
- [ ] 앱이 뒤로 가 있어도 신호를 놓치지 않는다 (포그라운드 서비스 필요, 이번 범위 밖)
