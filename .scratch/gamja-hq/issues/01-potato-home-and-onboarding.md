# 01: 감자 홈과 첫 만남

**What to build:** 앱을 처음 열면 감자의 이름과 외형을 정하고 두 가지 동의(운행 기록, 감자 교류)를 따로 고른 뒤 홈에 들어간다. 홈에는 내 감자가 보이고 시간대에 맞는 인사를 한다. 새로고침해도 감자가 그대로다. Astryx 테마와 앱 뼈대(홈, 작전일지, 임무, 설정 이동)가 이 티켓에서 선다.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 처음 열면 온보딩이 뜨고, 이름을 비우면 다음으로 갈 수 없다
- [x] 외형(품종, 소품)을 고르면 미리보기 감자가 바로 바뀐다
- [x] 두 동의는 서로 독립이고, 둘 다 꺼도 홈에 들어갈 수 있다
- [x] 홈의 인사가 시각(아침, 낮, 저녁, 밤)에 따라 달라진다
- [x] 새로고침 뒤에도 감자 이름, 외형, 동의가 유지된다
- [x] 밝은 테마와 어두운 테마에서 모두 읽을 수 있다
- [x] 차량 가로 화면과 휴대폰 폭에서 가로 스크롤이 없다
