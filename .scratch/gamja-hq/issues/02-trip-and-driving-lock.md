# 02: 운행 세션과 주행 잠금

**What to build:** 시뮬레이터 서랍에서 시나리오를 고르고 차량 신호(탑승, 출발, 정체 진입, 정체 해소, 주차)를 보내면 운행 세션이 진행된다. 감자의 대사와 표정이 단계마다 달라지고, 홈에 오늘의 운행 카드가 보인다. 주행과 정체 단계에서는 화면이 잠겨 감자와 한 줄 안내만 보인다.

**Blocked by:** 01

**Status:** resolved

- [x] 시나리오(퇴근길, 출근길, 주말 나들이)를 고를 수 있다
- [x] 현재 단계에서 보낼 수 있는 신호만 버튼이 켜진다
- [x] 허용되지 않는 순서의 신호는 상태를 바꾸지 않는다
- [x] 주행·정체 단계에서는 메뉴 이동과 입력이 불가능하고 한 줄 안내만 보인다
- [x] 주차 신호를 받으면 잠금이 풀린다
- [x] 감자 대사는 시각, 단계, 시나리오처럼 확인된 사실만 언급한다
- [x] 시뮬레이터에는 "시뮬레이션" 표시가 있고 앱 본체와 구분되어 보인다
- [x] 운행 중 새로고침해도 세션이 이어진다
